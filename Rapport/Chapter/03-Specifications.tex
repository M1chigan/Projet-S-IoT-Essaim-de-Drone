\section{Objective}
The purpose of this project is to fly a swarm composed of 3 drones and try to lift off a payload using a net. While this is the ultimate goal, an intermediate objective
would be to make the 3 drones keep a formation and move together to a given position.
\section{Project work}
\begin{itemize}

    \item UWB precise distance measurement system
    \item Implementation of a formation controller 
    \item ESP-NOW communication
    \item Go back and forth keeping the drone formation 
    \item Software-in-the-loop (SITL) simulation
    \item Creation of visualization tools for test

\end{itemize}

\section{Deliverables}
\begin{itemize}

    \item Report with all progress, advancements and explanation of technical knowledge
    \item Functional and commented UWB code 
    \item Methodology and results of the calibration of UWB sensors
    \item Bibliographical Study
    \item Video of demonstration 
    \item Functional Corrector (C/C++)
    \item Functional ESP-NOW communication
    \item Functional ESP32 code implementation (C/C++)
    \item Full simulation environement based on  Ardupilot and Mission Planner (Python)
    \item Functional visualisation tools (Matlab)

\end{itemize}
