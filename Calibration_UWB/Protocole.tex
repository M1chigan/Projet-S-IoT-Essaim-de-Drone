\subsubsection{Conclusion sur l'orientation}
D'après les essais précédents et les résultats, il est visible que l'orientation verticale semble avoir de meilleure performance de façon globale que le module à plat. 
Dans la suite des essais, nous serons donc toujours avec un module vertical.
